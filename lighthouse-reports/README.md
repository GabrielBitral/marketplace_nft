# Auditorias Lighthouse

Os relatórios HTML e JSON desta pasta são gerados por `npm run audit:lighthouse` após uma build otimizada em execução. Cada execução mede início e detalhe do NFT três vezes nos perfis desktop e mobile; `summary.json` registra a mediana, LCP, CLS, TBT e as condições de ambiente.

Os resultados devem ser interpretados no ambiente descrito no resumo. Pontuações abaixo da meta são mantidas como evidência, sem simplificação exclusiva da interface para elevar a nota.
